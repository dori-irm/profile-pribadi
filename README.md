# Halaman Web Profil Pribadi - Dori Irmawan

Proyek halaman web profil pribadi yang responsif menggunakan HTML5, CSS3, JavaScript, dan Bootstrap 5, serta dipublikasikan melalui GitHub Pages.

## Live Demo
Akses halaman web secara online melalui tautan berikut:  
[https://dori-irm.github.io/profil-pribadi/](https://dori-irm.github.io/profil-pribadi/)

## Struktur Direktori
- `index.html` — Struktur utama halaman web.
- `css/style.css` — Kustomisasi tampilan, warna, tipografi, dan responsivitas.
- `js/script.js` — Interaktivitas navigasi dan pembaruan elemen dinamis.
- `img/` — Aset gambar profil.
